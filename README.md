# Productivity Time Tracker App

Cross-platform mobile application built with Flutter to track time spent on
daily activities and personal goals.

##  Purpose
Instead of using checklists, the app measures actual time invested in tasks,
helping users evaluate consistency and long-term progress.

##  Features
- Task-based time tracking using timers
- Custom weekly goals per activity
- Progress visualization over weeks and months (planned)
- Clean and intuitive UI

##  Tech Stack
- Flutter
- Dart

##  Roadmap
- Weekly and monthly progress dashboards
- Data persistence improvements
- Exportable reports
